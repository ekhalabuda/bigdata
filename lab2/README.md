## Description

Обработка данных о задержках авиарейсов с использованием Apache Spark и Hadoop HDFS:

1. Использован датасет со 150,000 строками и 6+ признаками
2. Развернут Hadoop (1 NameNode + 1/3 DataNode) с ограничением памяти
3. Реализовано Spark-приложение с замерами времени и памяти
4. Проведено сравнение производительности для 4 конфигураций: 1 DataNode base, 1 DataNode opt, 3 DataNode base, 3 DataNode opt
5. Применены оптимизации: кэширование (`cache()`), репартиционирование (`repartition()`)


## To run one node:

```bash
docker-compose-1dn up -d
./run.sh
```

## To run three nodes:
```bash
docker-compose-3dn up -d
./run.sh
```
