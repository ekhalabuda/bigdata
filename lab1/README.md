### Description
Application provides a simple way to analyze selected stocks.

 You can:
 - Check historical metrics
 - Monitor real-time data
 - Make predictions using Linear Regression or exponential MA

Use navigation button on the left.

### Launch
To build and run the Docker container, use the following command:
```
docker-compose up --build
```
After the build completes, navigate to `http://localhost:8501/` in your web browser to access the application.
